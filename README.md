## 👨‍💻 Quem sou eu

Tenho **16 anos** e sou um estudante apaixonado por **Cibersegurança** e **Segurança Ofensiva**.

Minha jornada começou aos 15 anos com programação em **Python**. Depois migrei para o desenvolvimento web backend (Flask, APIs, WebSockets, Linux e servidores). Foi durante a criação de uma aplicação do zero que me interessei profundamente por segurança — tanto da aplicação quanto da infraestrutura.

Hoje meu foco total está em construir uma base sólida em:

- Redes e protocolos  
- Linux  
- Segurança Web  
- Reconhecimento, enumeração e exploração  
- Privilege Escalation  
- Active Directory  
- Metodologias de Penetration Testing  

Atualmente estou seguindo o roadmap **pre security** da tryhackme.
